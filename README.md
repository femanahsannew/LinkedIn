# Friendship Newsletter

A beautiful, responsive HTML newsletter template about meaningful friendships and deeper connections.

## Description

This newsletter explores the truth about friendship - not the comfortable version, but the honest one. It features a podcast episode titled "Your Voice in My Headset - Friendship Episode" discussing:

- Why most relationships stay surface-level
- What real friendship costs you
- How identity shapes the way you connect
- Why strong friendships don't happen by accident

## Files

- `Friendship - newsletter.html` - The main newsletter template

## Features

- Responsive design with beautiful gradient backgrounds
- Professional email template styling
- Links to the podcast episode
- Engaging visual design with modern CSS

## How to Use

1. Open the HTML file in your web browser or email client
2. Customize the content as needed
3. Send via email or host on a web server
